# GO CHAK 高策传媒 · 公司官网

科技与创意驱动的全域活动服务商 —— 单页静态官网，纯 HTML/CSS/JS 零依赖。

## 在线访问
- GitHub Pages：https://sq139.github.io/GO-CHAK/

## 本地预览
将 `index.html` 与 `assets_web/` 目录放在同一级，用浏览器打开 `index.html` 即可。

- 联系我们（深圳总部 | 广州 | 香港 | 澳门）

## 技术说明
- 画质与速度平衡：`assets_web/` 目录 WebP 轻压缩（1600px/q80，体积减半），浏览器按需懒加载
- 深色科技风 + 品牌红 #E60012，移动端自适应
- 图片 Lightbox 支持双指缩放 / 双击放大 / 拖动查看
